# Clivo

**A simple inclinometer and spirit level for Android.** Lay it flat for a bubble level, stand it on an edge for an angle gauge.

No ads · No permissions · No internet · ~16 KB

[**⬇ Download Inclinometer.apk**](Inclinometer.apk)

---

## Features

- **Bubble level** — X and Y tilt plus total tilt, in degrees
- **Angle gauge** — stand the phone on any edge to measure slopes
- **Turns green** when level (within 0.5°)
- **Calibrate** — tap on a known level surface; long‑press to reset
- **Hold** — freeze the reading so you can read it later
- **Screen stays on** while you measure

## Install

1. Download [`Inclinometer.apk`](Inclinometer.apk) on your phone.
2. Open it and allow **Install unknown apps** when asked.

Requires Android 5.0 or newer.

## Build from source

Needs JDK 17+ and the Android SDK (platform 34).

```sh
./gradlew assembleRelease
```

The APK is written to `app/build/outputs/apk/release/`.
